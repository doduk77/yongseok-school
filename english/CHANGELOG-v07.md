# 야나도 한다고 v0.7 — 학습 UX 개선

현재 사이트: https://doduk77.github.io/yongseok-school/english/

## 적용한 기능

- **대화 평가:** 브라우저에서 질문과 대답의 관련성을 비교하여 `🟢 뜻이 통할 가능성 높음`, `🟠 추가 확인 필요`, `🔴 질문과 관련 낮음` 3단계 카드를 표시. 무관하거나 불명확한 답은 다음 질문으로 넘어가지 않고 재시도 가능.
- **평가의 한계:** 생성형 AI 또는 실제 미국인 청자의 이해도 평가가 아닙니다. 규칙 기반 추정이므로 장문의 새로운 표현을 잘못 판정할 수 있습니다.
- **단어장:** 전체 42개 주제의 선택 이름을 한국어로 변경. 1,438개 단어 중 약 399개에 개별 이모지 아이콘을 연결하고 나머지에는 반복되는 테마 그림 대신 두 글자 타일 표시. 그림 없이 단어만 표시하는 선택지도 제공.
- **가로세로:** 난이도 하(3~5글자), 중(4~8글자), 상(7~11글자)로 분리. 각각 400판. 20단어 이상 실제 교차 배치 조건을 검사. 클릭한 단어의 글자를 입력하면 자동으로 다음 칸에 커서 이동.
- **대화 퀴즈:** 문제와 세 개 답안 각각 독립된 미국식 TTS 듣기 버튼, 한글 번역 버튼. 문제와 모든 답안에 대한 단어 뜻 보기 버튼. 현재 등록된 360개 문답의 실제 고유한 252개 답안에 한국어 번역 작성.
- **음성:** 처음 입장할 때 여성/남성 목소리 선호 선택 및 미리 듣기. 학습 화면에서 변경 가능. 사용자의 Chrome/OS가 제공하는 미국 영어 음성을 선택하는 방식이므로 젊은 음색이나 특정 성별을 항상 보장하지 않음.
- **데이터 유지:** 기존 `yanado_v03`, `yanado_pet_v05` 로컬 저장 키를 그대로 사용. 번호 선택 로그인 없음. 학습·펫 전체 파일 백업/복원 제공.

## 구현되지 않은 사항

- 실제 의미 이해가 가능한 서버형 AI 대화 평가 및 자유 생성 대화
- 기기간 자동 계정 동기화
- 학습 단어 1,438개 모두에 각기 다른 독립 일러스트
- iOS 아이폰/아이패드 실기기에서의 발음 음질·음성 인식 전수 검증

운영비 0원 원칙 유지. 외부 유료 GPT API는 연결하지 않았습니다.
