## 현재 구현 내용

- 상황별 테마 **60개** × 기본 질문 3개 = **기본 회화 180개 문답**.
- 시간/동행자/기분 변수 **24조합**으로 **1,440개 상황 조합**을 만들 수 있음. 주의: 서로 다른 AI 작성 대본 1,440개가 아님.
- 기본 질문 이후 5~10회 이상 대화를 이어가는 규칙 기반 후속 질문 기능. 일부 추가 정보(동행자, 음식, 호텔, 비행기 등)에서 화제를 이어감.
- **'자유 AI 대화' 메뉴**는 현재 온라인 생성형 AI가 아닌 **오프라인 대화 연습 엔진**. GPT나 다른 AI API 연결 없음.
- 퀴즈: 회화 180개 문답과 24개 상황 설정으로 조합되는 문제, 실제 3지선다 풀이 및 기록.
- **중복 없는 529개 영어 단어**: 품목별 간단한 이모지, 영어 음성, 뜻 보기/숨기기, 암기 여부. 사용자의 원래 요구였던 단어별 오리지널 애니 이미지 제작은 아직 미완성.
- **퍼즐 번호 1~200**: 시드에 따라 다른 격자를 자동 생성. 격자에 실제 교차한 단어 수 확인(현재 실험 조건 23개), 단어 내 글자 입력 시 다음 칸 자동 이동.
- 한글 번역 버튼, 대화 중 단어 뜻 버튼, 음성 입력(Chrome 환경에서 지원되는 경우), 미국식 음성(en-US) 합성 (브라우저 음성 품질은 기기 의존).
- 수준 리포트는 **휴리스틱 내부 참고값**. 미국 원어민의 이해 가능성이나 공인 CEFR 능력 측정으로 오인하지 말 것.

## 무료 정책과 제한

- 음성 대화와 단어 읽기는 브라우저 기능을 사용하며 브라우저/OS에 따라 지원 여부 및 자연스러움이 달라집니다.
- 생성형 자유 AI 연동은 하지 않았습니다. OpenAI API는 ChatGPT 무료 계정과 별도로 과금되는 서비스이므로 비용 0원 요구에 맞춰 사용하지 않습니다.
- 향후 무료 할당량이 제공되는 AI 서비스를 연결할 경우 **무료 플랜에서만**, 사용량 상한과 자동 유료 전환 금지 설정을 우선 적용해야 합니다. 무료 할당량 소진 시 로컬 연습으로 전환합니다.
- GitHub Pages 공개 저장소에서 호스팅. GitHub 정책/제한은 변경될 수 있습니다.
- 정적 사이트에 있는 PIN은 개발자 도구로 확인할 수 있으므로 개인 정보를 보호할 보안 장치가 아닙니다.
- 사용자 발화 뜻 추론과 문법 자동 분석은 규칙 기반이며, 복잡한 추가 발언은 제대로 이해하지 못할 수 있습니다.
