# 야나도 한다고 — English Adventure v0.1

Chrome 웹사이트용 첫 실행 버전. Windows/아이폰/아이패드 미니/11인치 아이패드 반응형.

- 웹 경로: https://doduk77.github.io/yongseok-school/english/
- 사용자 요청 접속 코드: 2580 (주의: **프런트엔드 코드에 있는 간단 잠금이며 보안 인증이 아님**. 민감한 기록은 저장하지 말 것.)
- 구현: 테마 선택·랜덤, 규칙 기반 회화 연습, 브라우저 음성 합성/가능한 브라우저의 음성 인식, 대화 퀴즈, 40개 이모지 그림 단어, 20단어 교차 퍼즐 생성 시도·검증, 간단 의사전달 판정 기반 레벨, 로컬 학습 기록.
- 미구현: 외부 AI와의 자연스러운 무제한 대화, 의미 기반 평가, 전문 발음 채점, 수천 개의 검수 콘텐츠, 계정 동기화, 통일된 3D 애니 일러스트 및 캐릭터 동작.
- 현재 채점은 키워드 기반 예시이므로 진짜 미국인 청자 수준 평가가 아닙니다. 문법 오류가 있더라도 의도가 전달되면 성공하도록 설계했습니다.
- GitHub Pages가 저장소 main/(root)에서 활성화되어 있다면 위 링크에서 접근 가능. 그렇지 않으면 Pages 설정 후 열립니다.

## 향후 우선 과제
1. 서버 AI/실시간 음성, 비용 통제 및 실제 의도 이해 평가.
2. 적응형 레벨의 공정성 및 발화 신뢰도 검증.
3. 퍼즐 교차 배치 20개 보장하도록 생성 실패 시 재시도·검증 강화.
4. 오리지널 애니 스타일 그림/장면 제작과 대량 콘텐츠 배포.
5. 서버 인증 및 학습 기록 계정 동기화.
